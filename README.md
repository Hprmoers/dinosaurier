# AKTE 66 – Expedition ins verlorene Zeitalter

Interaktive Lern-Expedition zum Massenaussterben vor 66 Millionen Jahren (Prolog + 7 Missionen).

**Online:** https://hprmoers.github.io/dinosaurier/

**Offline:** `python3 tools/build.py --offline` erzeugt `dist/akte66-offline.html` – eine einzelne Datei
mit allen Bildern, die ohne Internet im Browser läuft.

**Bearbeiten:** Quellcode liegt in `src/`, Bilder/Audio in `assets/`. Danach `python3 tools/build.py`
ausführen; das erzeugt die neue `index.html`. Details: `CLAUDE.md`, `docs/ARCHITEKTUR.md`, `docs/LEARNINGS.md`.
